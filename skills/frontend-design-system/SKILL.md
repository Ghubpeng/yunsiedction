# frontend-design-system（React Bits + Cosmin 式视觉 + 教育 SaaS）

## 1. 定位

统一视觉语言，**不是模仿某个网站**，而是拆解成可执行的 Design Token 与纪律。素材来源：[React Bits](https://github.com/DavidHDev/react-bits)（动效组件库，复制进项目改造，不整包引入）。

## 2. 设计哲学（Design Philosophy）

- Premium / Minimal / Modern / Clean
- 高信息密度（学习场景需要一眼看到关键信息）
- 柔和圆角、强排版层级
- 微妙动效（Subtle motion，绝不喧宾夺主）
- 明/暗主题双支持
- AI-native 质感（AI 功能区域有可识别的统一视觉，但克制）

## 3. Design Token（强制，所有样式从 Token 出发）

| Token 组 | 约定 |
|---|---|
| 色彩 | 主色/辅助色/中性色/语义色（成功/警告/错误/信息）；全部 CSS 变量，明暗两套；渐变仅限 AI/品牌点缀 |
| 字体 | 标题/正文/辅助三级字号与行高；数字（成绩/余额）用等宽数字特性 |
| 间距 | 4px 基准栅格（4/8/12/16/24/32） |
| 圆角 | 小 6 / 中 10 / 大 16；卡片统一 |
| 阴影 | 3 档（悬浮/弹层/抽屉），柔和低对比 |
| 动效 | 微交互 150–300ms（ease-out）；页面入场 400–600ms；禁止 >600ms 的装饰动画 |
| 主题 | CSS 变量切换明暗；`prefers-color-scheme` 默认跟随 |

- Token 定义在 `src/styles/`（`frontend-development` 目录约定），**一处定义、全局引用**。
- 禁止页面级硬编码颜色/字号/间距（特殊场景先加 Token 再用）。

## 4. React Bits 使用清单（只在这些场景用）

| 场景 | 用途 |
|---|---|
| Hero / 首页 | Hero 动画、品牌展示动效 |
| 页面过渡 | 路由/弹层过渡 |
| 微交互 | 按钮、卡片 hover、点赞/收藏等反馈 |
| 数据可视化动效 | 学习报告、掌握度图表入场 |
| AI 相关视觉 | AI 思考态、打字流、生成进度、AI 面板 |
| 空状态 / Loading | 品牌化空态插画与加载动效 |
| 高级组件 | 按需选用（先评估体积与可维护性） |

**使用方式**：复制组件源码进 `src/components/` → 按 Design Token 改造 → 只保留所需动效；禁止整包引入、禁止连样式一起照搬。

## 5. 动效纪律（强制红线）

教育平台**核心操作界面不允许动画化**，效率与稳定性优先：

- 禁用动效区域：题目页、考试页、视频播放页、学习档案、后台表格与表单、支付流程。
- 允许动效区域：首页/Hero、营销页、学习报告展示、AI 对话面板、空态/加载。
- 所有动效必须：`prefers-reduced-motion` 可降级为静态；不阻塞交互（动画进行中也可操作）；元素数量受控（性能预算）。
- 后台（`admin-development`）一律静态。

## 6. 组件分层（强制）

```
基础组件库（决策点 #7，默认 Ant Design，唯一引入点）
   → 业务组件（基于基础库封装，业务语义命名）
      → React Bits 动效增强（仅 §4 允许场景，独立目录管理）
```

- 同一种基础组件只允许来自基础库；禁止混用多套 UI 库。
- 自定义组件必须：三态齐全（加载/空/错误）、可访问（键盘、对比度、aria）。

## 7. AI-native 视觉约定

- AI 功能区域统一识别符号（图标/渐变点缀/思考态样式），用户一眼知道“这是 AI 区域”。
- AI 输出渲染：Markdown 样式统一、引用溯源卡片统一（“本回答依据：…”样式，见 `ai-tutor`）。
- 保持克制：AI 视觉 ≠ 满屏光效。

## 8. 禁止事项（NEVER）

- 直接抄 Cosmin/其他网站整体布局（只拆 Token 与气质）。
- 每页自定义一套样式/颜色。
- 核心操作界面加动效；动画阻塞交互。
- 整包引入 React Bits 或混用多套基础 UI 库。
- 为炫技加动效；明暗主题只做一半。

## 9. 与其他 Skill 的关系

- 工程落地：`frontend-development`；后台克制要求：`admin-development`。
- 新增视觉资产/组件属设计系统变更，需在 PRD 备注（`product-prd`）。

## 10. 检查清单

- [ ] 新样式全部来自 Token，无页面级硬编码？
- [ ] 动效只在允许区域？reduced-motion 可降级？
- [ ] React Bits 组件已按 Token 改造且体积可控？
- [ ] 明暗主题双可用？
- [ ] 核心学习/考试/后台界面无装饰动效？
